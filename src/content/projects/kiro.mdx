# Kiro IDE

**Kiro** is our revolutionary Agentic IDE that enables spec-driven development. It integrates Claude models directly into the full workflow for automated code generation.

## Key Features

- **Spec-Driven:** You write the spec, Kiro writes the code.
- **Claude Integration:** Powered by the most advanced LLMs available today.
- **Fast:** Rust-based backend for instant code analysis.

### The Architecture

Kiro uses a complex microservices architecture built on Next.js and Rust.
